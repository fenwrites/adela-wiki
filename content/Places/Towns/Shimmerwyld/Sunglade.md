*A gnome grove built high up in the trees*


## Overview
An [[Inseore Gnomes|Inseore]] glade led by [[Agatha Sunglade]], whose homes are built high in the trees to be closer to the sun. A lift carries anyone up to the central buildings, and there's no shame in using it.

## Notable Features
- Nicky's Knacks, run by Nicola Sunglade: trade only, no coin.
