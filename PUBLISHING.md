# Publishing the Adela wiki

This folder is a [Quartz](https://quartz.jzhao.xyz) site. Your notes stay in the Obsidian vault; a sync script copies only player-safe ones here.

## What gets published

A note is published only if **all** of these are true:

- it lives in the vault's `World/` or `Sessions/` folder
- its frontmatter has `publish: true`
- it isn't `type: secret`

`DM/`, `Meta/`, `Unsorted/` are never read for publishing. `%% comments %%` are stripped, and links to unpublished notes turn into plain text.

## Commands (run from this folder)

```bash
npm run preview-all   # local preview of EVERY World note, http://localhost:8080 (never published)
npm run preview       # local preview of exactly what will go online
npm run sync          # refresh content/ from the vault before committing
```

Stop a running preview before `npm run sync`; rewriting content/ under a live preview crashes it.

The pages in `content/Browse/` (People, Places, Factions, Lore, Session Log) are generated by the sync from published notes, so they never mention private ones. Edit the `BROWSE` table in `scripts/sync-vault.mjs` to change how notes are grouped.

## Updating the live site

```bash
npm run sync
git add -A
git commit -m "Update wiki"
git push
```

GitHub Actions rebuilds and deploys the site a minute or two after each push.
